```Drinks Info Project```
- A command line based application which allows users to pull drinks info from a given menu, using the CocktailDB API.

```Info about the project```
This is a project that:
- Allows the user to fetch a menu of drinks based on their category - the category list is presented to the user and they're prompted to enter the category of drink that they wish to investigate:
<img width="300" height="300" alt="image" src="https://github.com/user-attachments/assets/0bb891f2-0bd2-4a2d-bfb4-9314b47e196e" />

- We then fetch a list of drinks for the given category, prompt the user to enter a "Drink ID", and finally fetch a list of information around that specific drink:
<img width="300" height="300" alt="image" src="https://github.com/user-attachments/assets/939ce25c-a311-4fb7-af32-a7f4dd17c258" />

```Technologies and Packages used```
- C#
- ConsoleTableExt package (for extending and display the console output)
- NewtonsoftJson package (for working with the JSON response.
- RestSharp (for making API / HTTP Requests)
