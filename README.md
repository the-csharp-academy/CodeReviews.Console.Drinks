# Cocktail Explorer - C# Console Application

This is a simple C# console application that demonstrates HTTP calls and API integration.

## 🎯 What This Application Does

The Cocktail Explorer allows users to:

1. Browse drink categories from TheCocktailDB API
2. Select a category to see available drinks
3. Choose a specific drink to view detailed information
4. See ingredients, measurements, instructions, and other details

## 🚀 How to Run

1. **Prerequisites:**

   - .NET 9.0 SDK installed
   - Internet connection (for API calls)

2. **Build and Run:**

   ```bash
   dotnet build
   dotnet run
   ```

3. **Follow the prompts:**
   - Choose a drink category
   - Select a specific drink
   - View detailed information
