The program is designed to display a list of drinks along with details for each one. It is intended for use by restaurant staff.

The program does not store data locally in a database but reads it via the provided API.

Upon startup, the program displays a list of beverage categories from which the user can make a selection or exit the program by choosing the "Exit" menu option.
<img width="1734" height="927" alt="image" src="https://github.com/user-attachments/assets/158f4897-0c14-4ada-9edb-320c13e7a6c5" />

After a category is selected, a list of drinks from that category is displayed. The user can select any item or return to the previous menu using the "Back" menu option.
<img width="1734" height="927" alt="image" src="https://github.com/user-attachments/assets/336b19cb-42f8-43d7-9f5a-05bd6e416ecb" />

Once a drink is selected, a menu displaying the drink's description and image appears. The user can then return to the category menu or exit the program.
<img width="1734" height="1795" alt="image" src="https://github.com/user-attachments/assets/57b561c5-bea5-48d7-a04a-31e1c6e92ad0" />

If the API is unavailable or there is no internet connection, the program will display an error message.
