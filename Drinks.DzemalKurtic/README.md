**Project requirements:**



* Create a system that allows the restaurant employee to pull data from any drink in the database.
* No need for SQL
* Just present the data from an external source
* Handle the errors so app doesn't crash





**How the App works?**



When a user starts the app, he sees a Categories Menu for different categories of drinks. User inputs the name of a category by typing it out.



After choosing a category Drinks Menu opens and there you can see every drink that's in the chosen category. User inputs the number code of the drink.



When you choose a drink user gets a detailed view of the drink chosen.
