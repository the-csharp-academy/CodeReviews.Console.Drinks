# Drinks Info Console Application

## Overview

A console based application that uses http requests to access webapi data 
and display that data to the user.

## Requirements

- Must use database accessed through an API
- Allows user to pull data on any drink in the database
- Do not display empty values
- Handle errors if API is down

## Challenges

- Add a favourite drinks menu
- Display drink images
- Add a view count

## Technologies

- C#
- Sqlite
- Spectre.Console
